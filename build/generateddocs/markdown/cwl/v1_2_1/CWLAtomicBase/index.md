
# CWLAtomicBase (Schema)

`ogc.cwl.v1_2_1.CWLAtomicBase` *v1.2.1*

Direct CWL definition instead of the graph representation. Shared by the root CommandLineTool/ExpressionTool document and its nested-in-step form; not typically profiled on its own.

[*Status*](http://www.opengis.net/def/status): Under development

## Examples

### CommandLineTool at the document root
A `CommandLineTool` defined directly at the document root, without the `$graph` wrapper — the
typical shape for a single-tool Application Package. No `id` is needed since there is nothing
else in the document to cross-reference it.

#### json
```json
{
  "class": "CommandLineTool",
  "baseCommand": ["echo", "first"],
  "inputs": {
    "in": {
      "type": "Any"
    }
  },
  "outputs": {
    "out": {
      "type": "string",
      "outputBinding": {
        "glob": "out.txt",
        "loadContents": true,
        "outputEval": "$(self[0].contents)"
      }
    }
  },
  "stdout": "out.txt"
}

```

```ttl
@prefix cwl: <https://w3id.org/cwl/cwl#> .
@prefix ns1: <https://w3id.org/cwl/cwl#CommandOutputBinding/> .
@prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix sld: <https://w3id.org/cwl/salad#> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

<https://example.org/in> sld:type <https://example.org/Any> .

<https://example.org/out> cwl:outputBinding [ ns1:glob "out.txt" ] ;
    sld:type xsd:string .

[] a cwl:CommandLineTool ;
    cwl:baseCommand ( "echo" "first" ) ;
    cwl:inputs <https://example.org/in> ;
    cwl:outputs <https://example.org/out> ;
    cwl:stdout "out.txt" .


```


### ExpressionTool with no inputs
An `ExpressionTool` computing its output purely from an inline expression, with an empty
`inputs` list.

#### json
```json
{
  "class": "ExpressionTool",
  "inputs": [],
  "outputs": {
    "output": "Any"
  },
  "expression": "$({'output': null})"
}

```

#### jsonld
```jsonld
{
  "@context": "https://ogcincubator.github.io/bblocks-cwl/build/annotated/cwl/v1_2_1/CWLAtomicBase/context.jsonld",
  "class": "ExpressionTool",
  "inputs": [],
  "outputs": {
    "output": "Any"
  },
  "expression": "$({'output': null})"
}
```

#### ttl
```ttl
@prefix cwl: <https://w3id.org/cwl/cwl#> .

[] a cwl:ExpressionTool ;
    cwl:outputs "Any" .


```

## Schema

```yaml
description: Direct CWL definition instead of the graph representation.
allOf:
- $ref: https://ogcincubator.github.io/bblocks-cwl/build/annotated/cwl/v1_2_1/CWLProcessFields/schema.yaml
- properties:
    class:
      description: CWL class specification. This is used to differentiate between
        single Application Package (AP)definitions and Workflow that chains multiple
        packages.
      enum:
      - CommandLineTool
      - ExpressionTool
      title: Class
      type: string
      x-jsonld-id: '@type'
  required:
  - class
title: CWL atomic definition
type: object
x-jsonld-extra-terms:
  CommandLineTool: https://w3id.org/cwl/cwl#CommandLineTool
  ExpressionTool: https://w3id.org/cwl/cwl#ExpressionTool
x-jsonld-prefixes:
  cwl: https://w3id.org/cwl/cwl#

```
